# Лендинг для подбора вахтового персонала

Коммерческий лендинг для сбора заявок от кандидатов на вахтовую работу. Проект создается как упрощенная и более быстрая версия предыдущего сайта: основной акцент сделан на понятной подаче вакансий, расчете потенциального дохода и отправке заявки координатору.

В текущем состоянии репозиторий содержит базовую HTML-версию сайта, переданную как рабочая основа для дальнейшей доработки, подключения форм, таблицы заявок, политики конфиденциальности и рекламной аналитики.

## Стек

- HTML5
- Tailwind CSS через CDN
- Vanilla JavaScript
- Lucide Icons
- Google Fonts

## Моя роль

Проект ведется мной самостоятельно: от разбора требований заказчика и адаптации готовой основы до дальнейшей настройки форм, аналитики, пикселей, размещения и проверки сайта перед запуском рекламы.

В рамках подготовки я:

- разобрал переданную HTML-основу;
- выделил ключевые пользовательские сценарии;
- подготовил отдельный проект и git-репозиторий под новый сайт;
- зафиксировал текущую версию как стартовую точку для дальнейшей разработки.

## Что уже есть в основе

- Первый экран с позиционированием кадрового центра и ключевыми преимуществами.
- Форма быстрого подбора вакансии.
- Каталог открытых специальностей с фильтрами по направлениям.
- Карточки вакансий с краткими условиями и кнопкой отклика.
- Калькулятор дохода за вахту с выбором срока и специальности.
- Модальное окно для фиксации выбранной ставки и отправки анкеты.
- Блок порядка оформления на вахту.
- Блок условий для соискателей.
- Финальная анкета кандидата с полями имени, телефона, вакансии, даты рождения, города и согласий.
- Адаптивная верстка под десктоп и мобильные экраны.

## Планируемые подключения

Эти части еще не являются рабочими интеграциями в текущей стартовой версии и будут добавлены после утверждения данных заказчика:

- отправка заявок в Google Таблицу;
- VK Pixel / Top.Mail.Ru с целевыми действиями для рекламного кабинета;
- политика конфиденциальности и согласие на обработку персональных данных;
- доменные метатеги, favicon, Open Graph preview и базовые SEO-файлы;
- проверка форм и событий перед запуском рекламы.
